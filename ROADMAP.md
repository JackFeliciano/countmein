## Roadmap

CountMeIn holds a guest list per event with a seat limit, a visibility, three answers and a wait list that keeps the order of the replies. The hand-written runner carries 17 checks.

1. Add event editing so hosts can update event details before publication without changing the published event's day.
2. Add clearer guest list views so hosts can review going, maybe and no answers alongside the day each reply arrived.
3. Add wait list views so guests and hosts can see the reply order and identify who takes the first released seat.
4. Add event history so hosts can review cancellations and understand which events no longer accept guests.
5. Expand the hand-written test runner to cover more combinations of seat limits, late yes replies, released seats, restricted visibility and cancelled events.
